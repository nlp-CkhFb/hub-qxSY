## 结论
1. **判别式深度模型整体优于规则与 BiLSTM-CRF 基线。** 规则方法的触发词 F1 为 0.6168，BiLSTM-CRF 为 0.8080；而 BERT/CRF 与 RoBERTa/CRF 均提升至约 0.81—0.83。说明预训练语义表示能显著改善事件触发词识别。
2. **BERT 与 RoBERTa 在线性分类头下表现接近。** BERT + Linear 的 trigger/argument/event F1 分别为 0.8278/0.5584/0.1578，RoBERTa + Linear 为 0.8181/0.5456/0.1617。BERT 在触发词和论元抽取上略强；RoBERTa 的事件级 F1 略高，差异较小。
3. **增加 CRF 后，论元和事件级 F1 进一步提升。** BERT + CRF 相比 BERT + Linear，argument F1 从 0.5584 提升到 0.5808，event F1 从 0.1578 提升到 0.1703；RoBERTa + CRF 相比 RoBERTa + Linear，argument F1 从 0.5456 提升到 0.5790，event F1 从 0.1617 提升到 0.1677。序列转移建模对论元边界和组合事件有一定帮助。
4. **解码期硬约束带来最明显的论元和事件级收益。** 在不重新训练的情况下，BERT 的 argument F1 从 0.5808 提升到 0.6583（+0.0775），event F1 从 0.1703 提升到 0.2131（+0.0428）；RoBERTa 的 argument F1 从 0.5790 提升到 0.6653（+0.0863），event F1 从 0.1677 提升到 0.2288（+0.0611）。硬约束能有效减少非法标签转移和非法论元结构，是本次实验中性价比较高的改进。
5. **综合看，RoBERTa + CRF + 解码期硬约束是本表中的 strongest 论元和事件级方案。** 虽然 BERT 的硬约束方案 trigger F1 略高（0.8468 vs 0.8372），但 RoBERTa 在 argument F1（0.6653）和 event F1（0.2288）上更高，因此更适合作为论元抽取和完整事件抽取的主要方案。
6. **性能提升需要结合训练成本与延迟权衡。** Linear 模型训练约 307 秒；BERT + CRF 约 373 秒，RoBERTa + CRF 约 500 秒。硬约束复用已有 checkpoint，训练成本为 0，仅在推理阶段增加约束解码；但其推理延迟仍取决于原模型为 7.51 ms/句（BERT）或 17.47 ms/句（RoBERTa）。
**总体结论：** 使用预训练编码器优于传统模型；CRF 能提升序列标注效果；解码期硬约束在不额外训练的情况下进一步提升 argument F1 和 event F1。若以完整事件抽取效果为主要目标，建议选择 **RoBERTa + CRF + 解码期硬约束**；若更关注触发词识别或推理速度，BERT 系列具有一定优势。
