# RoBERTa 激活尺度诊断（补充实验）

主表使用原始 RoBERTa（`WEEK07_EMISSION_SCALE=1.0`）。本文件记录把 encoder 输出乘以 2.0（对齐 BERT 的隐状态尺度）后的对照，用来判断「RoBERTa 差」是预训练表示问题还是优化/尺度问题。

## 设置

- 同一数据、同一 149 标签、同一 3 epoch / 有效 batch 32 / lr 2e-5 / seed 42。
- `src/backbones.py` 中 `WEEK07_EMISSION_SCALE` 环境变量控制缩放，默认 1.0；主表不受影响。
- 校准系数 2.0 ≈ BERT 隐状态 std 0.825 / RoBERTa 0.383（约 2.15），未在 dev 上调参。

## 结论

1. 尺度校准把 RoBERTa Linear 的论元 F1 从 0.2058 提到 0.4263，证明原始崩溃主要来自激活尺度/优化，而不是标签或评测 bug。
2. 校准后 CRF 相对 Linear 仍有显著收益（+4.99pp 论元），硬约束再把论元从 0.4762 提到 0.6208；方法结论在 RoBERTa 上复现。
3. 即便校准，RoBERTa 同方法仍显著低于 BERT（硬约束下论元 −4.02pp、事件 −5.00pp），说明 3 epoch 预算内它没有追平 BERT；是预训练质量、收敛速度还是 checkpoint 转换损失，需要更多 epoch / 多 seed 才能分离。
